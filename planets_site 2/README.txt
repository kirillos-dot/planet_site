САЙТ «СОЛНЕЧНАЯ СИСТЕМА» — шпаргалка для защиты
================================================

Файлы:
  index.html           - главная страница
  planets.html         - Планеты (закладки, разделы, альбом)
  big_saturn.html      - большое изображение 600x400 по центру
  table.html           - таблица
  forms.html           - две формы отправки на сервер
  passport.html        - "DOM_JS. Считываем информацию из DOM"
  passport_latin.html  - "Изменяем кириллицу на латиницу по клику"
  task.html            - "Решение алгоритмической задачи" (задача 1009)
  img/                 - все картинки

ГДЕ КАКОЕ ТРЕБОВАНИЕ
--------------------
1. Текстовые и графические ссылки в текущем окне - навигация вверху каждой страницы
   (target="_self"; графическая ссылка - картинка logo.png внутри <a>)
2. Ссылка на закладку другой страницы - "Планеты: переход на закладку «Марс»" (planets.html#mars)
3. Внешний сайт в новом окне - "Википедия..." и значок W (target="_blank")
4. Переход на начальную страницу - "Главная страница" и картинка-логотип
5. Текущее положение - пункт текущей страницы выделен <b> и подписью "вы здесь"
6. Закладки внутри страницы - planets.html: справа вверху "Раздел 1, 2, 3",
   после каждого раздела "К началу страницы" (href="#top")
7. Списки нумерованные, ненумерованные, вложенные - index.html (<ul>, <ol>, списки внутри списков)
8. Изображения с пояснениями - index.html (Солнце, Земля), planets.html
9. Миниатюра (100px) -> большое изображение 600x400 в новом окне по центру -
   index.html и table.html (ссылка на big_saturn.html)
10. Таблица: фон всей таблицы (background у <table>), изображение в ячейке,
    изображение, гиперссылки - table.html
11. Форма с контактами (фамилия, имя, группа, телефон, почта, дата) - forms.html, форма 1
12. Своя форма (заказ телескопа): text, number, radio, checkbox, date, password, hidden,
    значения по умолчанию (value, checked, selected) - forms.html, форма 2
13-14. DOM и JS: passport.html, passport_latin.html, task.html
15. Загрузить папку целиком на сервер (например, в ~/public_html/)

Куда отправляются формы: https://httpbin.org/post - сервер, который показывает
в новом окне все полученные данные. Адрес можно заменить на свой в атрибуте action.

ЧТО НУЖНО ПОМЕНЯТЬ НА СВОЁ
--------------------------
1. passport.html и passport_latin.html - свои ФАМИЛИЮ, ИМЯ и ДАТУ РОЖДЕНИЯ
   (остальные данные паспорта можно оставить выдуманными).
   В passport_latin.html дата написана словами ("15 марта 2005 г."), чтобы при
   клике тоже менялась на латиницу.
2. forms.html - свои фамилию, имя, группу, телефон, почту в форме 1.
3. Скриншот: открыть passport.html, нажать F12 -> Console, ввести команды
   (они написаны внизу страницы), сделать скриншот и сохранить его
   вместо файла img/dom_screenshot.png (с тем же именем).

КАК ОБЪЯСНИТЬ JS (коротко)
--------------------------
passport.html:
  document.getElementsByTagName('p') - все абзацы страницы (массив), [3] - четвёртый по счёту.
  .childNodes[1] - второй "ребёнок" абзаца: [0] - текст "Фамилия: ", [1] - <span>Иванов</span>.
  .innerText - текст внутри элемента. .slice(-4) - последние 4 символа (год).

passport_latin.html:
  letters - таблица "русская буква -> латинские буквы".
  translit(text) - идёт по строке буква за буквой (цикл for), заменяет каждую русскую букву.
  onclick="toLatin()" - при клике на кнопку вызывается функция toLatin().
  document.getElementById("surname") - находим элемент по id и меняем его innerText.

task.html (задача 1009):
  parseFloat - превращает текст из поля в дробное число.
  Треугольник существует, если все стороны > 0 и X+Y>Z, X+Z>Y, Y+Z>X.
  Прямоугольный, если X*X+Y*Y=Z*Z (или другие две комбинации) - теорема Пифагора.
  Числа дробные, поэтому сравниваем с погрешностью: Math.abs(разница) < 0.000001.
  Кнопка "Отправить на сервер" сначала решает задачу, потом отправляет форму (submit()).
